# MicroTools

A collection of free, fast, privacy-first micro tools for developers, designers, and writers.
All processing happens entirely in your browser — no data leaves your device.

## Tools

| Tool | Description |
|------|-------------|
| JSON Formatter | Format, validate, and minify JSON |
| JWT Decoder | Decode JSON Web Tokens |
| Base64 Encoder/Decoder | Encode and decode Base64 strings |
| Case Converter | Transform text between case styles |
| Text Analyzer | Word, character, sentence counter |
| Password Generator | Generate strong random passwords |
| Color Converter | Convert HEX ↔ RGB ↔ HSL |
| QR Code Generator | Generate downloadable QR codes |
| Image Compressor | Compress images client-side |

## Stack

- React 19 + Vite 8
- React Router DOM
- Lucide React (icons)
- browser-image-compression
- qrcode.react
- Hosted on Netlify / Vercel

## Local Development

```bash
npm install
npm run dev
```
